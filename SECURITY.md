# Security

Craft MCP Hub runs local servers that let AI clients drive desktop apps, so a flaw in it matters. What it protects against, and what it doesn't, is in the [README](README.md#security).

## Reporting a problem

Please don't open a public issue for something that could put people who use the hub at risk. Use **Report a vulnerability** on the repository's [Security tab](https://github.com/AndrianLeah/craft-mcp-hub/security/advisories/new) instead: it reaches the maintainer privately. Say which version (`crafthub --version`) and system you are on, and how to reproduce it.

Only the latest release is supported: a fix goes into a new release.
